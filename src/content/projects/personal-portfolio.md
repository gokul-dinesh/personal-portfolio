This site is a static Astro build deployed to GitHub Pages on every push to `main`.

- Content lives in Markdown files under `src/content/` with frontmatter validated at build time.
- Ships zero JavaScript except a tiny dark-mode toggle.
- RSS feed, sitemap, tag pages and drafts work out of the box.
